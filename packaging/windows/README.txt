Bilingual Manga Reader and Mokuro Converter — Windows

1. Extract the complete ZIP.
2. Double-click "Bilingual Manga.exe".
3. Add manga. The reader opens in your normal Chrome profile.

Everything in the library is stored on this computer. No account or developer
tools are required. Yomitan is used through the user's normal Chrome extension.

The first time Mokuro conversion is used, its private OCR engine and model files
are downloaded into the user's application-data folder. Manga pages are never
sent to an OCR service. Later reading and conversion work locally.

On first launch, the app also caches about 14 MB of naming and matching metadata
from the Bilingual Manga archive linked below. It does not download manga pages.
Ordinary Mokuro and raw imports continue to work if that metadata is unavailable.

Bilingual Manga archive data and compatible sets:
https://github.com/B-M-dev/Bilingual-Manga-archive

If the app does not open, keep every extracted file together and see the log at:
%APPDATA%\Bilingual Manga Reader and Mokuro Converter\logs\launcher.log
